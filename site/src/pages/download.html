Requirements

Windows
Windows 10 or 11, 64-bit. Windows Defender Firewall must be present (it always is). To change rules, run the StockFW (Elevated) shortcut; everything else works without administrator rights.
Linux
An x86-64 distribution with GTK 3 (libgtk-3-0), liblzma (liblzma5) and OpenSSL 3 (libssl3, which provides libcrypto.so.3; Debian 11 and Ubuntu 20.04 ship only OpenSSL 1.1 and are refused by the installer), iptables and ip6tables; nft and curl for threat-intel blocklists and country blocking. Tested on Debian, Kali, Ubuntu and WSL2. Reading events and applying rules need root; sudo /usr/local/bin/StockFW is the full tool.

Step-by-step instructions: Install on Windows, Install on Linux.

Build from source

The release is built from the tag v{{release}} in the repository. The same code builds on either platform in a few commands.

Build on Windows (MSYS2)

Install MSYS2, open the UCRT64 shell (as administrator if you want to apply rules from the build), then:

$ pacman -S --needed base-devel git mingw-w64-ucrt-x86_64-{toolchain,gtk3,pkg-config,ninja,cmake,xz,openssl}
$ git clone --branch v{{release}} {{repo}}.git
$ cd StockFW/port
$ cmake -S . -B build -G Ninja
$ cmake --build build
$ ./build/StockFW.exe

To make the installer from the build, run installer/build_installer.sh; it stages the GTK runtime beside the executable and fails if any launcher still carries old branding.

Build on Linux

$ sudo apt install build-essential cmake ninja-build pkg-config git libgtk-3-dev liblzma-dev libssl-dev iptables nftables curl
$ git clone --branch v{{release}} {{repo}}.git
$ cd StockFW/port
$ cmake -S . -B build-linux -G Ninja
$ cmake --build build-linux
$ sudo ./build-linux/StockFW                      # the desktop app
$ ./build-linux/stockfw status                    # the command line

To make the same tarball the release ships, run tools/build-linux.sh (a stripped Release build) and then installer/linux/build_installer_linux.sh. tests/test-release.sh checks the result against the version in CMakeLists.txt, the changelog section and the licence list, as CI does for every release.

Uninstall

Windows
Settings → Apps, or the Uninstall shortcut in the StockFW Start menu folder. Firewall rules StockFW created stay in Windows Firewall; remove them with Stop firewall in the app first, or in wf.msc (they are all named StockFW-…).
Linux
sudo /usr/local/bin/stockfw-uninstall removes the binaries, the menu entry and the icons. Your policy in ~/.stockfw or /etc/stockfw is kept; delete it yourself if you want it gone.
