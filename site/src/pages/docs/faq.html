Questions and answers

About the product

Does StockFW replace Windows Firewall or iptables?
No. It configures them. The engine your system already has keeps doing the filtering, which is why StockFW has no driver, needs no reboot, and leaves the firewall exactly as it was when it is closed, crashes or is uninstalled.
Does anything leave my computer?
Nothing. There is no telemetry, no update check, no account and no network client. The dashboard listens on 127.0.0.1 only. The threat-intel feature downloads lists, each only after you turn it on and accept its publisher’s terms. The security model spells this out.
Is the Copilot an AI?
Not in the sense of a language model. It is a deterministic parser for what-if questions and a set of per-program counters with explained thresholds. It works offline and cannot be prompt-injected because there is no prompt.
Why is there no “deny inbound” rule kind?
Because inbound is denied by default. Every inbound rule is an exception that allows something; to block a source again you remove the allow. Outbound is the mirror image: allowed by default, with deny rules as the exceptions, and an optional restrictive mode that flips it.
Where is the Windows command line?
There is none. stockfw is Linux only; on Windows, the app is the whole tool. The core it links against is portable, so the gap is a packaging one, not a design one. [[gap]]
Which licence?
The repository carries two texts: the inherited GPLv2 in COPYING for the original code, and Apache-2.0 in LICENSE. The README says which applies to what, and the question of a single licence for the whole is open. [[gap]]

Reboot and persistence

What happens to my rules at reboot?
[[win]] Windows Firewall rules persist; StockFW’s rules are ordinary rules in it, so they are in force from boot, before any program runs. [[linux]] iptables rules live in the kernel and are gone at boot. StockFW does not install a boot service, so the policy is in force again when you press Start firewall, run sudo stockfw start, or turn on Start firewall on program startup and start the app. To have it at boot without StockFW running, add stockfw start to a systemd unit or rc.local. StockFW does not ship such a unit. [[gap]]
If StockFW crashes, am I unprotected?
No. The engine keeps the last applied rules. What you lose is monitoring, learning and Sentinel until you start it again.

Linux

iptables or nftables?
StockFW drives iptables and ip6tables, which on every current distribution are the nftables-backed versions, so its rules land in nftables and nft list ruleset shows them. The threat-intel sets use nft directly, in their own table. The policy itself has no native nftables backend. [[gap]]
Does it fight with ufw, firewalld, Docker or libvirt?
StockFW owns its own chains (INBOUND, OUTBOUND, STOCKFW-DNAT, STOCKFW-SNAT) and replaces only those; rules other tools keep in the same tables are not touched, and the loads use --noflush. Two tools both setting a default policy on INPUT will still disagree about what the default is, so run one host firewall manager at a time; ufw and firewalld are alternatives to StockFW, Docker and libvirt coexist with it.
Why root, and not polkit or a setuid helper?
Because a desktop program that can silently rewrite the firewall is a worse posture than one that asks for root openly. StockFW never raises its own rights. More.
Which distributions?
Tested on Debian, Kali, Ubuntu and WSL2. Anything with GTK 3 and iptables should work; the installer checks libraries by soname, not by package name, so renamed packages do not fail it.

Windows

Why two shortcuts?
The ordinary one runs with your rights and can read, edit and simulate; the elevated one asks for administrator rights once and can change the firewall. Keeping them separate means a program running as you cannot borrow the elevated window. Install on Windows.
Why is the installer not signed?
A code-signing certificate is a cost the project has not taken on yet. Check the SHA-256 on the download page instead; it tells you the same thing a signature would. [[gap]]
Does it work with a third-party antivirus firewall?
StockFW manages the Windows engine. If another product has replaced Windows Firewall as the active firewall, StockFW’s rules exist but that product decides.

Versions

Which version do these pages describe?
{{version}}, the release on the download page. The app shows its version in the sidebar and in About; stockfw status prints it.
What do the stamps on these pages mean?
“Verified” names an automated test that proves the sentence, “Measured” gives a number from an experiment that was run, and “Limit” marks something StockFW does not do. The welcome page explains each.
