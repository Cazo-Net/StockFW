The Windows installer is not code-signed, so SmartScreen will show “Windows protected your PC”. Choose More info, then Run anyway, after you have checked the checksum below. Code signing is on the roadmap; until then the checksum is your verification.

Check the download#

Compare the output with the matching line in SHA256SUMS.txt.

PowerShell (Windows)
PS> Get-FileHash .\StockFW-1.0.5-Setup.exe -Algorithm SHA256
Terminal (Linux)
$ sha256sum -c SHA256SUMS.txt --ignore-missing
StockFW-1.0.5-linux-x86_64.tar.gz: OK

Requirements#

Windows
Windows 10 or 11, 64-bit. Windows Defender Firewall must be present (it always is). To change rules, run the StockFW (Elevated) shortcut; everything else works without administrator rights.
Linux
An x86-64 distribution with GTK 3 (libgtk-3-0) and iptables. For IPv6 filtering in 1.0.7, ip6tables as well. Tested on Debian, Kali, Ubuntu and WSL2. Reading events and applying rules need root; sudo /usr/local/bin/StockFW is the full tool.

Build on Windows (MSYS2)#

Install MSYS2, open the UCRT64 shell (as administrator if you want to apply rules from the build), then:

MSYS2 UCRT64 shell
$ pacman -S --needed base-devel git mingw-w64-ucrt-x86_64-{toolchain,gtk3,pkg-config,ninja,cmake}
$ git clone https://github.com/Cazo-Net/StockFW.git          # main: the 1.0.7 development code
$ cd StockFW/port
$ cmake -S . -B build -G Ninja
$ cmake --build build
$ ./build/StockFW.exe

To make an installer from the build, run installer/build_installer.sh; it stages the GTK runtime beside the executable and fails if any launcher still carries old branding.

Build on Linux#

Debian, Kali, Ubuntu, WSL2
$ sudo apt install build-essential cmake ninja-build git libgtk-3-dev iptables
$ git clone https://github.com/Cazo-Net/StockFW.git          # main: the 1.0.7 development code
$ cd StockFW/port
$ cmake -S . -B build-linux -G Ninja
$ cmake --build build-linux
$ sudo ./build-linux/StockFW                      # the desktop app
$ ./build-linux/stockfw status                    # the command line

To make the same tarball the release ships, run installer/linux/build_installer_linux.sh after building.

Version strings

A build from the 1.0.7 branch still reports 1.0.6 in About and --version until the release bump, which is the last commit before a release. The features are there; the number lags.

Uninstall#

Windows
Settings → Apps, or the Uninstall shortcut in the StockFW Start menu folder. Firewall rules StockFW created stay in Windows Firewall; remove them with Stop firewall in the app first, or in wf.msc (they are all named StockFW-…).
Linux
sudo /usr/local/bin/stockfw-uninstall removes the binaries, the menu entry and the icons. Your policy in ~/.stockfw or /etc/stockfw is kept; delete it yourself if you want it gone.
